# Simple File Encryptor

A simple Python GUI application to encrypt and decrypt files using Fernet (symmetric encryption).

## Features
- Generate encryption key
- Encrypt any file (creates .enc file)
- Decrypt .enc files

## How to Run
1. Install cryptography: `pip install cryptography`
2. Run: `python file_crypt.py`

## Warning
- Keep `secret.key` file safe. Don't share it!
